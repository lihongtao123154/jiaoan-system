╚══════════════════════════════════════════════════════╝

本系统支持三种使用方式，按推荐程度排序：


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
方式一：本地运行 + ngrok 远程访问（推荐，立即可用）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【前提】确保已经安装了 Node.js

【第一步】双击运行「启动服务器.bat」
  - 会自动启动网页服务器和远程通道
  - 本地访问: http://localhost:3000

【第二步】找到远程地址
  - 会弹出 cmd 窗口显示 ngrok 信息
  - 找到 "Forwarding" 那一行:
    https://xxxx.ngrok.io -> http://localhost:3000
  - 把 https://xxxx.ngrok.io 这个地址发给其他老师即可

【第三步】其他老师打开这个链接就能用
  - 默认管理员账号: admin / admin123
  - 你可以在系统里添加其他老师的账号

【注意】
  - 你的电脑不能关机/休眠，否则远程地址失效
  - 每次重启 ngrok 地址会变，需要重新分享
  - 首次使用可能需要注册 ngrok 账号（免费）:
    1. 打开 https://dashboard.ngrok.com/signup
    2. 注册后复制 Authtoken
    3. 在命令行运行: ngrok authtoken 你的token


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
方式二： Railway 云部署（24小时在线，国外平台）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 注册 Railway 账号: https://railway.app
2. 安装 Git，把项目上传到 GitHub
3. 在 Railway 中连接你的 GitHub 仓库
4. 选择 Deploy，Railway 会自动识别 Node.js 项目
5. 部署完成后 Railway 会分配一个 https://xxx.railway.app 域名

【注意】
  - Railway 免费套餐每月 $5 额度，够用
  - 数据存储在 JSON 文件中，重启会丢失
  - 如需持久化存储，建议改用 SQLite


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
方式三： Zeabur 云部署（国内访问快，推荐中国用户）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 打开 https://zeabur.com 注册（支持微信登录）
2. 创建项目 → 选择「从 GitHub 部署」
3. 上传项目代码到 GitHub 仓库
4. 连接仓库后 Zeabur 会自动部署
5. 部署后可在设置中绑定自定义域名

【优势】
  - 国内访问速度快
  - 支持微信/支付宝付款
  - 有免费额度
